# 0088 M4 384-pixel challenger

## Decision

Keep 224 pixels as the selected input size for later comparisons. The 384-pixel candidate scored
lower on the frozen model-selection view, had lower macro F1, and took more time to train and infer.
This decision uses reviewed selection crops only. It does not qualify model quality or
generalization.

## Classification results

The 384-pixel run completed eight epochs and 4,792 steps. It used a frozen ViT-S/16 encoder, CLS
head, source-safe augmentation, seed 17, batch size 1, AdamW learning rate 0.001, zero weight
decay, MPS, and fp32. It used the same 599 training and 209 model-selection crops as M3.

| Measure | 224 pixels | 384 pixels | Change |
| --- | ---: | ---: | ---: |
| Face-up top-1 | 206/208 (99.04%) | 204/208 (98.08%) | -0.96 pp |
| Face-up top-3 | 208/208 (100%) | 205/208 (98.56%) | -1.44 pp |
| All-crop top-1 | 207/209 (99.04%) | 205/209 (98.09%) | -0.96 pp |
| Macro F1 | 98.84% | 98.11% | -0.73 pp |
| Training time | 996.7 s | 3,761.7 s | 3.77x |

All 208 face-up IDs match the M3 and Gemini reference rows. Compared with 224, 204 crops were
correct for both, none were correct only at 384, two were correct only at 224, and two were wrong
at both sizes. The 384-only errors were two `SPADES_QUEEN` crops from `IMG_0662`, predicted as
`SPADES_KING`. Both sizes also missed the same two `SPADES_ACE` crops from `IMG_0657`, predicted
as `CLUBS_ACE`.

Compared with Gemini on the exact same 208 face-up crops, 199 were correct for both, five were
correct only for 384, four only for Gemini, and none were wrong for both. The classifier scored
204/208; Gemini scored 203/208. These paired observations are not independent evidence of
generalization.

The 384 source-group results were 114/116 and 90/92 across two groups. The frozen three-group
support floor is not met. One `FACE_DOWN` selection crop was classified correctly. This single crop
does not measure face-down precision, recall, calibration, or generalization. It remains suitable
for the accepted iterative annotation-assistance objective only.

## Runtime and memory

The exported bundles were run through `DinoV3IdentityClassifier` on MPS. It classified all 209
frozen selection crops from their canonical PPM bytes. Both bundles reproduced the saved top-1 and
top-3 predictions for all 209 crops.

| Measure | 224 pixels | 384 pixels |
| --- | ---: | ---: |
| Mean crop-to-prediction | 41.54 ms | 101.09 ms |
| Median crop-to-prediction | 38.68 ms | 97.90 ms |
| 95th percentile | 47.92 ms | 113.03 ms |
| Peak observed MPS driver allocation | 111.9 MB | 153.8 MB |
| Process maximum resident set | 621.2 MB | 623.0 MB |

The 384 mean latency is 2.43x the 224 mean. MPS allocation is the maximum sampled after each
crop; it is not a system-wide unified-memory peak. Process resident-set size was similar.
