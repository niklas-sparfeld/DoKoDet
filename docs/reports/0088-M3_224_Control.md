# 0088 M3 224-pixel control

## Result

The frozen real-only control completed all eight epochs. It uses a frozen DINOv3 ViT-S/16 encoder,
a CLS linear head, 224-pixel input, source-safe augmentation, MPS, and fp32. The fit took 996.7
seconds (16m37s) for 4,792 steps. It used 599 reviewed training crops and 209 reviewed model-selection
crops. The final test stayed unopened.

The best checkpoint scored 207/209 top-1 (99.04%) and 209/209 top-3 on the model-selection view.
Face-up top-1 was 206/208 (99.04%; Wilson 95% interval 96.6–99.7%). Macro F1 was 98.84%. The only
target misses were two `SPADES_ACE` crops in `cardeventnet-IMG_0657`, both predicted as
`CLUBS_ACE`. The single `FACE_DOWN` selection crop was classified correctly.

The source-group results were 114/116 face-up crops for
`source-group-9d6d4824b53bc4a9` and 92/92 for `source-group-d4543cb23cc73b35`. Only two source
groups contribute. The frozen three-group minimum is not met, so a source-group bootstrap interval
and quality qualification are not available.

## Paired Gemini comparison

All 208 face-up sample IDs match the exact Gemini M2 crop receipts. DINOv3 classified 206 correctly;
Gemini classified 203 correctly. The difference is +1.44 percentage points for DINOv3. Both models
were correct on 201 crops, only DINOv3 was correct on five, and only Gemini was correct on two. The
two DINOv3 errors were both correct for Gemini. The Gemini Wilson 95% interval is 94.5–99.0%.

This is model-selection evidence from two source groups. It does not establish the frozen quality
gate or generalization. Do not compare these results to the retained 0043 PoC point estimate, which
uses a different historical input set.

## Support and limits

The training set has one unique `FACE_DOWN` crop. The sampler selected it 28 or 29 times per epoch;
those repeated exposures do not increase the number of independent samples. The model-selection
view has one `FACE_DOWN` crop, and the confidence-calibration view has none. The observed one correct
selection prediction supports iterative annotation assistance only. It does not measure face-down
precision, recall, calibration, or generalization. The user accepts this support level for iterative
classifier work.

Face-up class counts range from 7 to 15 model-selection crops. No class spans the required three
groups; class counts above 10 still miss the group minimum. Report per-class observations as
diagnostics only. No confidence policy was fit, automatic crops were not evaluated for this
milestone, and no final-test data was opened.
